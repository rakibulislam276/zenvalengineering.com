Audco Gate Valve

Audco Gate Valve, Globe Valve and Check Valve Dealer and Supplier in India.

Audco Gate Valve is an industrial valve designed to control the flow of fluids within pipelines. These valves operate using a sliding gate or wedge mechanism that moves up and down to either allow flow or completely block it.

Gate valves are typically used in applications where full flow or complete shut-off is required, as the gate moves perpendicular to the direction of fluid flow.

Key Features & Characteristics

  • Gate Design: Uses a wedge or parallel sliding gate to control fluid flow through the valve.
  • Construction Materials: Manufactured using forged steel, stainless steel, carbon steel, or alloy steel depending on application requirements.
  • Various End Connections: Available with flanged, butt-weld, socket-weld, and threaded connections.
  • Multiple Pressure Ratings: Designed to operate under pressure classes such as Class 150, 300, 600, 900, 1500, and 2500.
  • Wide Size Range: Available in various sizes to accommodate different pipe diameters and flow requirements.
  • Rising or Non-Rising Stem Options: Rising stem valves provide visual indication of valve position, while non-rising stem designs are used where vertical space is limited.
  • Reliable Isolation: Ideal for on/off control where minimal pressure drop is required.
  • API Standards Compliance: Manufactured according to relevant industry standards including API specifications.
