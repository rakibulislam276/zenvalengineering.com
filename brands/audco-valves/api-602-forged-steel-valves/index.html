Audco API 602 Forged Steel Valves

Audco Forged Steel Gate, Globe and Check Valve Dealer, Exporter and Supplier in India.

Audco API 602 Forged Steel Valves are designed and manufactured according to the specifications defined by the American Petroleum Institute (API) Standard 602. These valves are commonly used for compact forged steel gate, globe, and check valve applications in refineries and petrochemical plants.

These valves are engineered to withstand high pressure and high temperature conditions while delivering reliable sealing performance and long service life.

Key Features & Characteristics

  • API 602 Design Standard: Manufactured according to API 602 specifications for forged steel valves.
  • Forged Construction: Produced through forging processes that enhance valve strength and durability.
  • Compact Design: Suitable for installations where space is limited.
  • High Quality Materials: Manufactured from carbon steel, stainless steel, or alloy steel depending on the application.
  • Multiple Pressure Classes: Available in pressure ratings such as Class 150, 300, 600, 800, 900, 1500, and 2500.
  • Various End Connections: Threaded, socket weld, butt weld, and flanged connections available.
  • Wear Resistant Trim Materials: Internal components such as disc, seat and stem are made from materials designed for high durability.
  • API Monogram Certification: Many valves meet API certification standards for quality assurance.
